# Студия «Кот Барсик» — сборка серии без телефона

Настоящая страница приложения (`multik.html`, ветка `mebel-3d`) открывается в Chrome на Mac GitHub Actions;
скрипт `studio.js` подменяет телефон: голос Apple — `tts_mac.swift`, нейроголос — `voice.html` (ветка `multik-voice`),
кадры и звук — в ffmpeg. Потом `qa.py` делает приёмку: файл, листы кадров, громкость, слова по сценарию, паспорт голосов, «никто ни в ком» (тест движка `vnutri.js`: двое героев не стоят друг в друге дольше 1,5 с; найдено — `qa.json: ok=false`, поле `vnutri`), «край кадра» (тест движка `kraj.js`: на средних планах край кадра не режет героя пополам; найдено — замечание в `notes`, поле `kraj`).

- Запуск: положить сценарий в `scripts/<имя>.txt` (со строками ПЕРСОНАЖ для Барсика, Пика и Рона) и вписать `<имя>` в `request.txt`.
- Итог: `runs/<имя>/` (журнал, `result.json`, `qa/qa.json`, листы кадров); видео — в релизе `studio-<имя>`.
- На YouTube ничего не выкладывает.

## Голоса героев
- `golosa.json` — голоса, утверждённые Михаилом на слух; сборщик ставит их героям по имени в каждой сборке (нейроголос из каталога `BARSGolos.CATALOG` движка). 17.11.2026: Филя — «крошка» (ru_alfia, F 1.2, P 1.4); Топа — ru_miyau, F 1.12, P 1.4, R 1.15.
- Проба голосов: `scripts/golosa<K>.txt` + строка в `request.txt` с `--golos=Имя:тип[:P=…:F=…:T=…:R=…],…` (нейроголос) или `--fx=Имя:тембр` (тембр голоса iPhone). `Имя:off` — голос как раньше.

## Выкладка на YouTube (канал «Кот Барсик», @cartoon_friend3)
- `publish.txt` → задание `publish` (`publish.py`, `yt_barsik.py`). Строка: `check` | `draft <релиз> <серия>` | `plan <релиз> <серия> <ГГГГ-ММ-ДДTЧЧ:ММ МСК>` | `cancel <id>` | `stats`. Итог — `youtube/status.txt`, `youtube/<релиз>.json`, `youtube/channel.json`.
- Серия уходит только закрытой: черновиком (`draft`) или с таймером выхода (`plan`). Название, описание и обложка берутся со страницы супруги (ветка `mebel`, `s9kbars/serii.json`), видео — из релиза `studio-<релиз>`. «Для детей» — да.
- Вход — секрет репозитория `BARSIK_YT`. Делается один раз: `barsik-login.sh` на первом сервере (ключ Google от бота «Білесің бе?»), код на google.com/device вводит **владелец** канала — «менеджера» из прав доступа Studio YouTube к API не пускает (справка YouTube, 17.11.2026). Ключей в ветке нет.
- Публиковать — только по правилам из документа проекта `claude/multik-avtomat.md`: серия прошла приёмку, Михаил знает время выхода и может отменить.
