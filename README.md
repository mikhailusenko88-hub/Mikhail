# Слух для музыки (ветка muzyka-sluh)

Положить звук в `in/` (wav/mp3/m4a), запушить — workflow `muzyka-sluh` разберёт новые файлы и закоммитит в `out/`:
- `<имя>.md` — отчёт: плач-индекс и свет-индекс, настроение по обученным сетям Essentia (грусть, радость, валентность,
  теги mood/theme, инструменты, стиль), CLAP (на какое описание похоже: «плач», «надежда», «эпика», «голос воет»…),
  лад и аккорды, темп, громкость, разбор главной мелодии (подъезды, скольжения, вибрато, «вздохи»), полосы звука, щелчки.
- `<имя>.png` — спектр с линией мелодии, громкость с аккордами, настроение по времени.
- `summary.md` — таблица всех разобранных файлов.

Слово `force` в `request.txt` — разобрать всё заново. Только свою музыку: репозиторий открытый.

## Студия (studio/)
Код синтеза музыки (numpy/scipy, без сэмплов): `theme.py` — инструменты, шина, зал, мастеринг; `cathedral.py` — орган, хор, колокола;
`quartet.py` — пиццикато, спиккато; `svoboda.py` — формантный женский голос, рамочный барабан, шейкер; `rassvet.py` (A/B) — светлая
версия в духе «Now We Are Free»; `enc.py` — двухпроходная нормализация громкости (linear) в m4a.
Запуск: `cd studio && python3 rassvet.py A && python3 enc.py rassvet_A.wav out.m4a`.
