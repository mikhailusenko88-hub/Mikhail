# shorts — ежедневная нарезка Shorts «Кот Барсик»

Каждый день в 07:00 МСК (или вручную: Actions → shorts-barsik → Run workflow) скрипт:
1. берёт список серий с Rutube-канала (запас — YouTube @Cartoon_Friend3, потом episodes.txt);
2. выбирает серию строго по порядку номеров: 5, 6, 7, 8… (настройка `start_from`), уже нарезанные пропускает;
3. по звуку ищет самые живые моменты (смех, крики, действие), не повторяя уже взятые;
4. режет 1080×1920: кадр серии посередине, размытый фон, сверху «КОТ БАРСИК» + название, снизу «полная серия — на канале»;
5. кладёт mp4 + превью в Release `shorts-kids`, пишет `feed.json` на страницу ветки `mebel` → http://89.126.192.214:8080/mebel/s9kbars/

Настройки — `config.txt`. Что уже взято — `state.json` (удалить запись серии = брать заново).


## Сервер (основной режим с 07.11.2026)
Нарезка идёт на сервере 89.126.192.214: `server/install.sh` ставит `/usr/local/bin/shorts-cut` (cron 07:00), скрипт `server/shorts-cut.py` подтягивается с этой ветки при каждом запуске. Серии — с YouTube 1080p, запас Rutube. Ролики: `/var/www/mebel/s9kbars-v/` (+feed.json), хранятся 14 дней. Настройки: `/var/www/shorts/config.txt`, лог: `/var/www/shorts/log.txt`. Ручной запуск: `shorts-cut 2` (2 ролика) или `shorts-cut 1 6` (1 ролик из 6 серии). GitHub-вариант остался как ручной запасной.

## Кнопка «Подписаться» (с 12.11.2026)
Под картинкой серии — красная кнопка «ПОДПИСАТЬСЯ» (с 1,5 с до конца ролика), за 3 с до конца лапка из-за правого края нажимает её — «✓ ВЫ ПОДПИСАНЫ». Та же кнопка и лапка, что в самих мультиках.
Картинки `server/sub1_red.png`, `sub1_done.png`, `sub1_paw.png` рисует `tools/multik/test/subpng.js` (ветка `mebel-3d`); сервер скачивает их один раз в `/var/www/shorts/sub/`.
Новые картинки — под новым именем (`sub2_…`) и новое имя в `SUB_FILES`. Выключить — `subscribe: 0` в `config.txt`. В описаниях «Подписывайтесь…» — сразу под первой строкой, у YouTube ссылка с окном подписки (`?sub_confirmation=1`).
В описаниях Shorts YouTube ссылки не нажимаются — для перехода на полную серию в YouTube Studio у Short есть «Связанное видео».
