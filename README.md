# Ролики-цитаты «Живые строки»
Движок: акварельная сцена рисуется сама, поверх — цитата (рус + англ), автор; оркестровая музыка генерируется.
- `schedule_30d.json` — общий план (по 90 роликов в месяц, по 3 цитаты): 1–90, 91–180 (`plan_month2.py`), 181–270 (`plan_month3.py`, 4 янв — 2 фев 2027).
- Банк цитат — `quotes_bank*.py` (часть 7 — третий месяц, `T(...)` — «заголовочная» цитата, идёт первой); картины — `quotecard.py`, `scenes2.py`, `scenes3.py`
  (зимний Тянь-Шань, замёрзшее озеро, снегири, фонарь, лунный лес, дерево на закате, кони в степи, морозное окно, подснежники).
- Музыка — `orchestra.py`: стили `ORCH` (первые два месяца) и `NEW3` (третий: перебор фортепиано и струнные, скрипка, кларнет, саксофон).
- `python3 render_day.py N` — рендер дня N в `out/`.
- Свои мелодии с низким голосом — `voice_music.py`, стили `golos_rassvet`, `golos_doroga`, `golos_prostor`, `golos_gimn`,
  `golos_kolybelnaya` (движок в `studio/`, `golos.py`): стерео, −23 LUFS (`voice_music.LUFS` — выбрано на слух:
  при −14 и −18 ролики казались громкими; прежняя музыка канала −16…−19). Под длину ролика (34–40 с) берётся вариант мелодии
  с вступлением или без (`golos.SHORTS`, `best_variant`), темп отходит от родного не больше чем на 4–8 %.
  С ролика №25 (13.11.2026) они стоят **через один** с прежней оркестровой музыкой: `python3 plan_voice.py 25`
  (прежний стиль хранится в поле `music_was`).
- Заменить только звук в готовых роликах (картинка не перерисовывается): в `remusic.txt` строка `days: 9-90`, запушить —
  `quotes-remusic.yml` обновит ветки `quotes-out-dXX`. Локально: `python3 remusic_day.py N <папка с роликами дня>`.
- Поменять `render.txt` и запушить в ветку `quotes` — GitHub Actions отрендерит дни из матрицы `quotes-render.yml` параллельно, каждый день — в ветку `quotes-out-dXX`.
Удержание (08.11.2026, по Studio: смотрели в среднем 15 с из 40 — уходили до второй цитаты): первая цитата ~8 с
(картина рисуется в 1/0,62 раза быстрее, `FIRST_SPEED`, `FIRST_TOTAL`), вверху полоса прогресса из 3 частей,
мелкая строка «дальше — ещё 2 мысли · 2 more ahead» под счётчиком с 3,5 с. Ролик ~34 с.
Шрифты: Prata, Cormorant Garamond, PT Serif (SIL Open Font License, `fonts/OFL.txt`).

## Автовыкладка на сервере
Установка (повторный запуск обновляет):
`curl -fsSL https://raw.githubusercontent.com/mikhailusenko88-hub/Mikhail/quotes/deploy_quotes.sh | bash`
Бот — `/root/quotes-bot`, команда `quotes` (status, login, check, now, pause, resume, log, update).
Cron каждые 10 минут; ролики выходят по порядку плана в 09:00, 14:00, 19:00 МСК, файл качается с GitHub перед выкладкой и удаляется после.
