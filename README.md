## Шаг 1. Полная копия, ничего не включая — `perenos/kopiya.sh`
Терминал Мака:
```
ssh -t root@206.168.213.210 'curl -fsSL https://raw.githubusercontent.com/mikhailusenko88-hub/Mikhail/perenos/perenos/kopiya.sh | bash'
```
Спросит пароль шведского сервера, потом (только в первый раз) — казахстанского. Дальше работает в фоне.
- боты, токены, данные — на те же места, что в Казахстане; /etc, crontab, ключи — в `/root/kz-kopiya/fs/`;
- нужные программы ставятся, но службы не запускаются; в расписание на шведском ничего не ставится;
- каждую ночь в 01:20 копия обновляется сама (`kz-kopiya stop` — убрать);
- защита: если казахстанский сервер переустановят или почистят — копия не перезаписывается.

Потом: `kz-kopiya otchet` — что скопировано; `kz-kopiya proverka` — каждый бот собирает пробный ролик без выкладки,
проверяются входы в YouTube и скачивание с YouTube со шведского адреса.

## Шаг 2. День переноса (готовится по описи после шага 1)
1. Последняя свежая копия.
2. В Казахстане убрать расписание (crontab и /etc/cron.d/gh-timer — с копией), чтобы ролики не вышли дважды.
3. На шведском — то же расписание и службы; убрать ночное копирование.
4. Проверить первый выход каждого бота.
Отдельно решить: 3D-страницы мебели и игра — на шведский или на сервер магазина (из России он открывается надёжнее).
