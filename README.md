# Голос «Альбина» для бота «Почему так?»

Бот роликов «Почему так?» читает текст нейроголосом **Альбина, мягкий тон** (Silero v5 CIS, лицензия MIT)
вместо Microsoft «Дмитрий». Ударения и «ё» — ruaccent, плюс свой словарь `albina_fix.json`; цифры читаются словами.

| Файл | Что делает |
|---|---|
| `albina.py` | кладётся рядом с `make_video.py` бота: подготовка текста, озвучка, запасной голос |
| `albina_worker.py` | озвучщик, живёт в `/opt/multik-tts` рядом с `server.py` (тот же голос, что у «Мультиков») |
| `patch_bot.py` | подключает `albina.py` к `make_video.py` (две вставки) |
| `patch_server.py` | добавляет в службу голоса `multik-tts` режим «bot»: ударения только в многосложных словах, «+ё», лёгкий подъём в вопросах без «почему/как»; адрес `/mark` — текст с ударениями для лога. «Мультики» не меняются |
| `deploy_albina.sh` | установка на сервер: `bash albina.sh` — поставить, `bash albina.sh back` — вернуть Дмитрия |
| `test/` | пробные ролики в GitHub Actions + проверка запасного голоса |

Если Альбина не загрузилась — ролик целиком выходит прежним голосом, выкладка не срывается.

## Проверка (3 ноября 2026, анализатор voice-check, 27 фраз)
| разметка | естественность (UTMOS) | ошибок ударений (+возможных) | интонация |
|---|---|---|---|
| как у «Мультиков» (ударения во всех словах) | 3,56 | 6 (+8) | 26/31 |
| режим «bot» | 3,59 | 3 (+3) | 27/31 |

Вопрос без вопросительного слова («Летучие мыши совсем слепые?»): без подъёма звучит как утверждение,
с `pitch="high"` на последнем слове появляется подъём (x-high — смазывает слова).
