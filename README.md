# Цвет при сборке видео — проверка

- `cvet_mac.swift` + `.github/workflows/cvet.yml` — сборка как в «Замер 3D» (JPEG → AVAssetWriter H.264) на Mac в GitHub Actions; результаты в `results/<runner>/`.
- `tools/cvet_test.py <папка_png> <папка_вывода>` — облачная сборка ffmpeg: «как было» (BT.601 без меток) против «стало» (BT.709 + метки), ΔE2000.
- `tools/izmer.py test results/<runner>` — замер mp4 с Mac (плеер читает матрицу по метке, без метки HD — BT.709).
- `test/` — таблица цветов (20 цветов «Мультиков» + волоски 1 px) и кадры Барсика, Пика, Рона.

Итог (4.11.2026): облачные сборки ffmpeg — ошибка до 6,5 (бирюза), 4,7 (глаза, ошейник), исправлено до <0,65.
Телефон: матрица уже BT.709, но без меток; JPEG 0,9 даёт ≤1,9 на почти чёрном/белом; волоски 1 px теряют цвет в любом 4:2:0.
