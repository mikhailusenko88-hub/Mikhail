# geroi3d-m — «картинка → 3D» для героев «Кот Барсик» (менеджер, 18.11.2026)
Вторая попытка после ветки `geroi3d`: вход чище, модель точнее. Разбор, почему с части обложек не выходило, — ветка `studio`, `proby/geroi62/ZAMECHANIYA.md`.
- `cfg.json` — вырезка головы с обложки (`box`) и многоугольник «оставить» (`keep`): чужие герои, лапы, кисти, сундук — вне его.
- `prep.py` — маска BiRefNet, жёсткая (без полупрозрачности), только голова; итог `in/<имя>.png`, предпросмотры `out/prep/`.
- `gen.py` — Hunyuan3D-2mini (обычная, 30 шагов, сетка 256), своё зерно на машину; итог `out/<имя>_s<зерно>.ply/.glb`.
- Запуск — строка в `request.txt`: `prep` или `gen imgs=fila26,topa23 seeds=1,2`.
