# Игры Михаила (ветка games)

Исходники браузерных игр. Мебель и всё остальное — в других ветках, здесь только игры.

| Папка | Что это |
|---|---|
| `core/` | общее ядро: экран, ввод, Playgama Bridge, реклама, звук, флаги, монеты |
| `g1-draw` … `g5-io`, `g5-factory` | прототипы под YouTube Playables / порталы |
| `online/` | онлайн-«Шарики» (Flagball): `server.js` — сервер на Node без зависимостей, `game.js` — клиент |
| `hub/` | страница для детей со всеми играми |
| `tests/` | проверки на playwright |
| `vendor/` | Playgama Bridge SDK и three.js для сборки |

Сборка прототипов: `./build.sh` → `dist/` (с SDK) и `dist-web/` (без SDK).
Тестовая онлайн-версия пока выкладывается на сервер через ветку `mebel` (`ip52gz08/online`), потому что сервер забирает только её.
