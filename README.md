# studio-bench — замер, а не бот

Разовый замер для решения по автоматической сборке серий «Кот Барсик» (17.11.2026):
может ли бесплатный Mac GitHub Actions рисовать кадры «как в кино» тем же движком, что и приложение
(ветка `mebel-3d`), и сколько секунд уходит на кадр. Ничего не публикует и никуда не выкладывает.

Запуск — изменить первую строку `request.txt`. Итог — `status/result.txt`, `status/sys.txt`, кадры `status/*.jpg`.
