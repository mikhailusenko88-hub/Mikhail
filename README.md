# Фоновая музыка для роликов

Вся музыка написана и синтезирована с нуля (свои мелодии, без чужих семплов).
Громкость всех треков выровнена до −18 LUFS. Под голосом в боте ставить `music_volume` ≈ 0.15.

| Папка | Что внутри |
|---|---|
| `kz/` | 4 трека в казахском стиле для «Білесің бе?» (уже в ветке `kz-bot`) |
| `ru/` | все русские треки: народный стиль, «Зимняя сказка» в 6 жанрах, лоу-фай и бум-бэп |
| `pochemu_tak/` | отобранные 7 треков для «Почему так?» + `music_by_format.json` (музыка по рубрике) |
| `src/` | исходники: `python3 src/kz_music.py OUT`, `ru_music.py`, `skazka_remix.py`, `lofi_pack.py` |

## «Почему так?» — какая музыка к какой рубрике
- **Факт дня** — «Зимняя сказка» (оригинал), «Вечерний чай» (лоу-фай)
- **Миф или правда** — «Старый двор» (бум-бэп), «Зимняя сказка» рэп-бит
- **Топ-3** — «Мотор» (бум-бэп), «Зимняя сказка» рэп-бит
- **Как это работает** — «Дождь» (лоу-фай), «Зимняя сказка» лоу-фай
- **Загадка** — «Зимняя сказка» (оригинал), «Старый двор»

## Подключение к боту на сервере
1. Скопировать файлы из `pochemu_tak/*.mp3` в папку `music/` рядом с `make_video.py`.
2. В `config.json` добавить `"music_volume": 0.15` и ключ `"music_by_format"` из `pochemu_tak/music_by_format.json`.
3. В `make_video.py` выбор трека — как в ветке `kz-bot` (подбор по `script["format"]`, иначе любой).
