# Kim yutadi? — гонки шариков для Узбекистана

YouTube-канал «Kim yutadi?» (@kimyutadi_uz). GitHub Actions 3 раза в день собирает Shorts-гонку и выкладывает:
~12:00 города · ~16:00 машины · ~20:00 футбольные клубы (время Ташкента); во всех названиях #shorts. Надписи — узбекский (латиница) + русский одинаково.
Сезон — неделя: в воскресенье финал топ-8 (города — вечером, машины — днём), с понедельника таблица заново,
чемпионы недель сохраняются (★).

- `.github/workflows/uz-race.yml` — расписание (копия лежит в `main`: расписание работает только оттуда)
- `uz_run.py` — один запуск: гонка → YouTube → таблица (`state.json`), отчёт `status/last.txt`, список роликов `status/uploads.md`
- Вид ролика (с 08.11.2026, после разбора Studio: 86% пролистывали): без отсчёта — ролик начинается, когда шарики уже летят;
  камера в 1,5 раза ближе и держит борьбу за тройку; вместо таблицы на 20 строк — полоса «топ-3»; подписи не налезают;
  заголовок через 4,5 с становится компактным; гонка 22–31 с (трасса 4–5 участков), ролик ~32–40 с вместо минуты.
  Настройки — вверху `race_video.py` (ZOOM, T0, WIN_MIN/WIN_MAX, SECTIONS).
- `race_video.py` — движок (тот же, что «Қай қала жеңеді?» у «Білесің бе?»), `race_leagues.py` — города, машины, клубы (CLUBS: цвет шарика = цвет клуба), надписи
- `yt.py`, `ytkey.py` — выкладка; ключ приложения Google — из секрета `FLAGBALL_YT`, вход в канал — `login/uz_token.json`
  (зашифрован ключом приложения, без секрета бесполезен)
- `request.txt` — ручной запуск: поменять и запушить. `mode: login` — вход в канал: код появится в `status/login.txt`,
  ввести на google.com/device и выбрать Kim yutadi?
- Добавить город по просьбе зрителей — строка в `CITIES` (`race_leagues.py`), запасные города там же в комментарии.
- Музыка — свои треки из `music/` (как у «Білесің бе?»), шрифт DejaVu Sans Bold, карта — Natural Earth (public domain).
