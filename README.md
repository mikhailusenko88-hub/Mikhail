# Flagball Arena — автовыкладка гонок 32 стран

**8 ноября 2026, сезон «3 жизни» (с сезона 2):** у каждой страны ❤️❤️❤️. Одно видео = одна гонка 24 стран
(первыми бегут те, кто бежал меньше), последние 7–8 теряют жизнь, без жизней — вылет. Сколько теряют, бот
подбирает сам, чтобы к финалу дожило ~40–50 стран. Сезон 2 — 68 гонок, гранд-финал 30.11 (слот 3) — 32 лучшие по
жизням (при равенстве — по среднему месту). Жизни видны везде: заставка, таблица справа, «-1 LIFE», «SAFE»,
счётчик ❤️❤️❤️/❤️❤️/❤️, обложка, описание. Shorts: первые 2 с — «IS YOUR COUNTRY HERE?».
Код: `season.py` (`migrate_to_lives`, `_life_*`). Старые правила сезона 1 — ниже.

**Трассы (8.11.2026):** 17 видов блоков. Новые: `glass` (стеклянный пол лопается от ударов), `sliders` (рампы ездят,
у стены открывается щель), `comb` (ходячие колышки), `pushers` (брусья из стен), `drum` (барабан с зубцами),
`split` (развилка: короткий путь за люком или длинный зигзаг). По воскресеньям — SUNDAY MEGA TRACK (этапы на 30% длиннее,
в основном новые блоки, анонс в конце субботних роликов). В гранд-финале последний этап кончается стеклянным полом.

**Ноябрь 2026, обновление:** одно видео = несколько заездов (отбор — по 2, 2-й тур — все 3, полуфиналы — оба, финал — один),
4–12 минут, с главами в описании. Обложка — три самых «кликабельных» флага заезда лицом к лицу + «WHO SURVIVES? ONLY N OF M»
(`thumb.py`, `popular.py`). Название начинается со стран («Russia vs Vietnam vs Egypt …»). К каждому видео — один Shorts
(`shorts.py`): финальный этап самого «кликабельного» заезда, вертикальная вырезка, ссылка на полное видео.

GitHub Actions 3 раза в день (≈07:00, 15:00, 23:00 МСК) собирает следующий заезд и выкладывает на YouTube-канал
Flagball Arena (@FlagballArenaTV): ролик, обложка, плейлист Daily Races.

Сезон на выживание (13 гонок ≈ 4,3 дня): отбор — все 193 страны в 7 заездах, выживают 96 → 2-й тур 3×32, по 16
→ полуфиналы 2×24, по 16 → гранд-финал 32 стран (7 этапов, один чемпион) → новый сезон. Состояние сезона
(заезды, выжившие, чемпионы, зал славы) — `season_state.json`, двигается только после удачной выкладки.
Сезон 1: заезд 1 — гонка #1 от 04.11 (выжили 15, кто дошёл до 4-го этапа).

- `.github/workflows/flagball.yml` — расписание (копия этого файла лежит в `main`, расписание работает только оттуда)
- `season.py` — правила сезона; `ci_run.py` — один запуск: заезд → обложка → YouTube → сезон; отчёт в `status/last.txt`, список роликов `status/uploads.md`
- `yt.py` — загрузка через YouTube API; ключ — секрет репозитория `FLAGBALL_YT` (в ветке ключей нет)
- `fb-login.sh` — разовый вход в канал на сервере (ключ Google от бота «Білесің бе?»)
- `request.txt` — ручной запуск: поменять первую строку и запушить (`mode: test` — без выкладки)
- генератор: `race.py`, `track.py`, `phys.c`, `render.py`, `audio.py`, `thumb.py`, `fastvid.py`
- `flags/` — флаги (flag-icons, MIT), `fonts/` — Poppins (SIL OFL)
