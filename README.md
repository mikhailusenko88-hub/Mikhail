# Студия «Кот Барсик» — сборка серии без телефона

Настоящая страница приложения (`multik.html`, ветка `mebel-3d`) открывается в Chrome на Mac GitHub Actions;
скрипт `studio.js` подменяет телефон: голос Apple — `tts_mac.swift`, нейроголос — `voice.html` (ветка `multik-voice`),
кадры и звук — в ffmpeg. Потом `qa.py` делает приёмку: файл, листы кадров, громкость, слова по сценарию, паспорт голосов.

- Запуск: положить сценарий в `scripts/<имя>.txt` (со строками ПЕРСОНАЖ для Барсика, Пика и Рона) и вписать `<имя>` в `request.txt`.
- Итог: `runs/<имя>/` (журнал, `result.json`, `qa/qa.json`, листы кадров); видео — в релизе `studio-<имя>`.
- На YouTube ничего не выкладывает.

## Голоса героев
- `golosa.json` — голоса, утверждённые Михаилом на слух; сборщик ставит их героям по имени в каждой сборке (нейроголос из каталога `BARSGolos.CATALOG` движка). 17.11.2026: Филя — «крошка» (ru_alfia, F 1.2, P 1.4); Топа — ru_miyau, F 1.12, P 1.4, R 1.15.
- Проба голосов: `scripts/golosa<K>.txt` + строка в `request.txt` с `--golos=Имя:тип[:P=…:F=…:T=…:R=…],…` (нейроголос) или `--fx=Имя:тембр` (тембр голоса iPhone). `Имя:off` — голос как раньше.
