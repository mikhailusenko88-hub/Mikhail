# golos — проверка озвучки «Мультиков» (кот Барсик)

Ветка без кода приложения. Здесь считается то, что нельзя посчитать в облаке Claude:
- `ep_listen.py` + workflow `golos-ep` — «послушать» готовые серии с Rutube: где ударение не там, какие слова смазаны (запуск: поменять `ep_request.txt`);
- результаты — папка `ep/<серия>/` (report.md, words.json, картинки фраз с ошибками).
`voice_check.py` — копия анализатора из ветки `voice-check`.
