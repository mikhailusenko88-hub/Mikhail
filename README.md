# music-ref — разбор мелодии-образца
`request.txt`: строка 1 — канал или ссылка на ролик, строка 2 — слова для поиска в названии (через `|`).
Push → GitHub Actions качает звук (в репозиторий не сохраняется), разбирает и кладёт отчёт в `status/report.md`, картинку — в `status/*.png`, список роликов — в `status/list.txt`.
