# golos-en — английские пробы голосов героев «Кот Барсик»

- `jobs.json` — герои, реплики (из серии 32 про компас), варианты голосов: `kokoro:<голос>` (Kokoro-82M, лицензия Apache 2.0) или `edge:<голос>` (Microsoft), целевая высота `f0`, сдвиг формант `F`, живость `range`, темп `dur`.
- `en_proby.py` — озвучка, подгонка высоты и тембра (Praat «Change gender»), замеры (высота, размах, HNR, разборчивость через Whisper base.en).
- Итог — `out/<герой>.mp3` (все варианты подряд с подписью «Вариант один…»), `out/v/<герой>_<N>.mp3`, `out/report.md`, `out/report.json`, `out/<герой>.png`.
- Запуск — push в эту ветку (меняется `request.txt`).

## Голоса героев на других языках (golos-klon)
- `refs/<герой>_ref.wav` — образец голоса (реплики 1–3 из серии 36, релиз `studio-36`, `golosa.zip`), `_held.wav` — реплики 0 и 4 для проверки мерки, `_ru.wav` — как звучит сейчас.
- `clone.json` — фразы по языкам. `en_clone.py`: способ A — Chatterbox Multilingual (MIT) клонирует голос по образцу; способ B — Kokoro читает с родным произношением, Chatterbox VC перекрашивает в голос героя. Высота подгоняется к образцу (Praat), если расходится больше 1,5 полутона.
- Проверка: сходство голоса ECAPA с образцом героя и с соседями, высота, HNR, разборчивость Whisper base.
- Итог — `out_klon/<герой>.mp3` (по-русски как сейчас + варианты), `out_klon/v/`, `out_klon/report.md`. Запуск — push с изменённым `request-klon.txt`.

## Дубляж серии целиком (dub) — вариант 2 «перекраска», выбран Михаилом 22.11.2026
- Студия (`studio`, `studio-m`) в каждой сборке кладёт в релиз `studio-<сборка>` файл `dub.zip`: `dub/lines/NNN.wav` (каждая реплика), `dub/lines.json` (время, герой, текст), `dub/me_NN.wav` (музыка и шумы без голосов), `dub/full.wav` (полное сведение).
- Перевод — `perevod/<серия>.json` (`ru`, `en`, `es`, `pt` по номеру реплики), соответствие сборка → перевод — `geroi.json → builds`, настройки голосов героев — `geroi.json`.
- Запуск: `dub-request.txt` = `<сборка> en es pt` → workflow `dub` (языки параллельно). Каждая реплика: источник с родным произношением (Kokoro / Piper / Chatterbox) → Chatterbox VC в голос героя (образец — его реплики из этой серии) → высота героя → длина как у русской (скоростью голоса) → громкость как у русской; до 3 попыток, если распознаватель (Whisper small) понял меньше 85 %. Сведение — громкость музыки и голосов по русскому миксу (сдвиг голосов ~5,7 мс), −15 LUFS как в студии.
- Итог: релиз `dub-<сборка>` (`dub_<язык>.wav` для YouTube Studio → Языки → Дубляж, `.mp3`, превью `ep-<сборка>-<язык>-540.mp4`), отчёт `out_dub/<сборка>/report_<язык>.md`.
- Пробы: `out_lab` (Пик и немецкий), `out_lab2` (хинди), `out_lab3` (немецкий Пик) — `dub_lab.py`, `lab.json`.
