# Голос «Альбина» для бота «Почему так?»

Бот роликов «Почему так?» читает текст нейроголосом **Альбина, мягкий тон** (Silero v5 CIS, лицензия MIT)
вместо Microsoft «Дмитрий». Ударения и «ё» — ruaccent, плюс свой словарь `albina_fix.json`; цифры читаются словами.

| Файл | Что делает |
|---|---|
| `albina.py` | кладётся рядом с `make_video.py` бота: подготовка текста, озвучка, запасной голос |
| `albina_worker.py` | озвучщик, живёт в `/opt/multik-tts` рядом с `server.py` (тот же голос, что у «Мультиков») |
| `patch_bot.py` | подключает `albina.py` к `make_video.py` (две вставки) |
| `patch_server.py` | добавляет в службу голоса `multik-tts` режим «bot»: ударения только в многосложных словах, «+ё», лёгкий подъём в вопросах без «почему/как»; адрес `/mark` — текст с ударениями для лога. «Мультики» не меняются |
| `deploy_albina.sh` | установка на сервер: `bash albina.sh` — поставить, `bash albina.sh back` — вернуть Дмитрия |
| `test/` | пробные ролики в GitHub Actions + проверка запасного голоса |

Если Альбина не загрузилась — ролик целиком выходит прежним голосом, выкладка не срывается.

## Проверка (3 ноября 2026, анализатор voice-check, 27 фраз)
| разметка | естественность (UTMOS) | ошибок ударений (+возможных) | интонация |
|---|---|---|---|
| как у «Мультиков» (ударения во всех словах) | 3,56 | 6 (+8) | 26/31 |
| режим «bot» | 3,59 | 3 (+3) | 27/31 |

Вопрос без вопросительного слова («Летучие мыши совсем слепые?»): без подъёма звучит как утверждение,
с `pitch="high"` на последнем слове появляется подъём (x-high — смазывает слова).

## Улучшение голоса (8 ноября 2026, анализатор voice-check)
- **Вопросы без «почему/как…»** («Верблюд хранит воду в горбу?»): начало фразы ниже (`pitch="low"`), подъём `x-high`
  на последнем слове (если оно односложное — ещё на одном-двух). Вопрос слышен в 6 из 7 проб, было 0 из 3.
  Настройки — `BOT_Q_PITCH`, `BOT_Q_BASE` в `patch_server.py`.
- **Слова без ударения** (ruaccent не знает: «Манцинелла», «Карибах», иногда пропускает соседние): ударение
  ставится отдельно по слову, иначе — на предпоследний гласный. Раньше Альбина угадывала и смазывала слово.
- Переозвучить всё заново: в `request-farm.txt` слово `force`. Бот хранит скачанные фразы в `albina_cache` —
  после такой переозвучки её очистить (`rm -f /root/clips-bot/albina_cache/*.mp3`), иначе концовка останется старой.

### Вопрос мелодией (8 ноября 2026, вечер — выбрал Михаил на слух, вариант 4)
Подъём через голос (`pitch="x-high"`) на слух вопросом не звучал. Теперь вопрос без вопросительного слова
озвучивается отдельно: последнее слово чуть медленнее (`rate="slow"`), потом в Praat (PSOLA, тембр не меняется)
голос перед последним словом проваливается на 3 полутона ниже средней высоты фразы и взлетает до +6,5 к самому
концу, без спада. Мелодия снята с живого образца Михаила («А ты это знал?»). Настройки — `BOT_Q_*` в `patch_server.py`.
Нужен `praat-parselmouth` в /opt/multik-tts/venv (ставится в voice-farm.yml); без него — только замедление.

## Слух «по звуку» (11–12 ноября 2026 — Михаил услышал «Ан ещё стоял» и «почти пить тысяч лет»)
Проверка всего банка (627 фраз): распознаватель слышал не тот текст в 139 фразах, после правок — в 88. Что изменено:
- **Слова из одного слога** получают ударение (кроме служебных: в, на, не, и, а, же, бы…; «что»-союз). Без «+» Альбина читала
  их как безударные: «он» → «ан», «пять» → «пить», «ток» → «так», «снег» → «сник». Список служебных — `_CLIT`.
- **Тире** модель не слышит (пауза была в 3 местах из 117). Теперь на его месте запятая + пауза `BOT_DASH_MS` (200 мс):
  голос остаётся «на весу». Одна пауза `<break>` без запятой не годится — голос падает, как перед точкой, и ударение
  съезжает («ДлИна. До тридцати метров»). «——» (двойное тире в тексте для голоса) — пауза в 1,6 раза дольше.
- **Звонкость на стыке** (`_assim`): после глухого согласного Альбина оглушала и следующий звонкий — «был сбит» → «спит»,
  «сгорит» → «скорит», «с головы» → «с коловы», «растут гуще» → «куще». Пишем, как звучит: «збит», «зголовы»,
  «растуд гуще»; «В тебе…» в начале фразы → «Ф тебе» (иначе «в» не слышно). Глухих слов было 17, осталось 5.
- **Не трогается то, что подобрано на слух 8 ноября:** концовка «А ты это знал?» (`BOT_KEEP`, звук бит в бит прежний)
  и короткие слова в хвосте вопроса, по которым идёт взлёт («…во сне?», «…в день?»).
- `albina.py`: фразы целиком — ключ `"_фразы"` в `albina_fix.json` («В ней яд.» → «В ней —— яд.»); «самому/самого…»
  (самый — «с+амаму старому», сам — «самом+у»); «Витамин А/С…» — буква читается названием; словарь ударений пополнен
  (начался, тонущему, отмершие, челюстями, искра, оси, строили, мочегонный → «мочиг+онный» — иначе звучит «мочевонный»).
- Ключи фраз не менялись (`VOICE_VER` тот же): всё это меняет только текст для голоса, бот на сервере обновлять не надо.
- Как проверять: ветка `golos` (stage_check.py — распознаватель + ударения; zvon — звонкость по спектру; сверка с эталонными
  голосами в ветке `voice-check`). Прежняя озвучка сохранена в ветке `pochemu-albina-voice-backup-1111`.
