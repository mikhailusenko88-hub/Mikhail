# Сервер магазина «Наш декор» (Selectel, Ubuntu 24.04)

Скрипт `setup-prostranstvo.sh` одной командой настраивает новый сервер:

- **nginx**: сайт открывается в корне `https://ДОМЕН/`; старый адрес `/mebel/0f7s1eez/`
  переадресует на главную, а файлы по старым ссылкам (фото `…/mebel/0f7s1eez/img/…`,
  `avito.xml`) отдаются как есть, поэтому фид Авито продолжает работать;
- **сайт из GitHub**: ветка `mebel`, папка `0f7s1eez`. Раз в минуту cron делает `git fetch`
  (по HTTPS, без ключей) + `reset --hard` в `/opt/prostranstvo-src` и копирует папку
  в `/var/www/prostranstvo`. Никаких «тихих» проверок: каждая ошибка пишется
  в `/var/log/prostranstvo-sync.log` и в журнал (`journalctl -t prostranstvo-sync`);
- **3D-библиотеки**: three.js r128 (`three.min.js`, `OrbitControls.js`) из npm-пакета
  `three@0.128.0` (с проверкой контрольной суммы) → `/mebel/_lib/…`;
- **HTTPS**: Let's Encrypt (`certbot --nginx`), продление автоматическое;
- **защита**: ufw (открыты только 22, 80, 443), fail2ban для SSH, автообновления
  безопасности (если нужна перезагрузка — ночью в 04:30 МСК), версия nginx скрыта,
  gzip, кеш картинок, отдельный пользователь `prostranstvo` для сайта.

Вход по паролю и порт SSH скрипт **не меняет** (чтобы не потерять доступ) — только
выводит рекомендации. База данных и CRM — отдельным этапом позже (заготовка в скрипте).

## Запуск (одна команда, от root)

```
curl -fsSL https://raw.githubusercontent.com/mikhailusenko88-hub/Mikhail/server/setup-prostranstvo.sh | bash -s -- nashdekor.ru ВАШ@EMAIL
```

Займёт 2–5 минут, в конце — сводка: адреса сайта, что работает, что сделать дальше.
Запускать на **новом** сервере Selectel. Если скрипт увидит чужие службы (Docker, VPN,
занятые порты — например, на старом сервере в Казахстане), он остановится, ничего не меняя.

Повторный запуск безопасен; без параметров берёт домен и email из
`/etc/prostranstvo/prostranstvo.conf`. Без домена (сайт пока по IP): `… | bash -s -- -`

## Как проверить

- `prostranstvo-status` — сайт, HTTPS, когда последний раз обновлялся из GitHub, защита, диск;
- в браузере телефона: `https://ДОМЕН/` (пока нет DNS — `http://IP-сервера/`);
- обновить сайт сразу, не дожидаясь минуты: `prostranstvo-sync --verbose`;
- журналы: `/var/log/prostranstvo-sync.log`, `/var/log/prostranstvo-cert.log`,
  `/var/log/prostranstvo-setup.log`.

## Сертификат HTTPS

Если при установке домен ещё не указывал на сервер, скрипт не падает: сайт работает по
http, а сертификат сервер сам пробует получить каждые 15 минут, как только DNS заработает.

1. reg.ru → домен → «DNS-серверы и управление зоной»: A-запись `@` → IP сервера,
   A-запись `www` → IP сервера, AAAA-записи удалить.
2. Подождать 15–60 минут и (если не хочется ждать) выполнить одну команду:

```
prostranstvo-cert
```

Она объясняет результат по-русски. `www` добавится в сертификат сам, когда появится его A-запись.

## Фид Авито

В `config.json` генератора фида: `"photo_base": "https://ДОМЕН/mebel/0f7s1eez/img/"`,
пересобрать `avito.xml` и залить в ветку `mebel` — через минуту он на сервере:
`https://ДОМЕН/avito.xml`.
