# mebel — страницы проектов мебели для клиентов

Каждая папка `<код>/index.html` публикуется сервером как http://89.207.252.121:8080/mebel/<код>/
Сервер забирает эту ветку раз в минуту. Цены и деталировка сюда не попадают.

## Реестр проектов
Нумерация: 100/1, 100/2, 100/3 … Номер — в заголовке страницы. Код в ссылке — случайный,
чтобы по номеру нельзя было подобрать чужой проект.

| Номер | Код | Что | Ссылка |
|---|---|---|---|
| 100/1 | ed1121q | Мебель санузлов: тумбы под раковину, шкафы над инсталляциями | http://89.207.252.121:8080/mebel/ed1121q/ |
| 100/2 | kalr50s | Шкаф с арочными фасадами, открытые стеллажи и стол у окна (МДФ плёнка) | http://89.207.252.121:8080/mebel/kalr50s/ |
