# Правила для всех чатов и задач Claude в этом репозитории

Репозиторий `mikhailusenko88-hub/Mikhail` — **открытый**: каждую ветку, каждый файл и каждое сообщение коммита видит любой человек.
Правило Михаила (26.11.2026): «чтобы не один всё чистил, а каждый за собой». Каждый чат сам следит, что он кладёт в GitHub, и сам убирает свои ошибки.

## Что нельзя класть в репозиторий
Ни в файлы, ни в сообщения коммитов, ни в названия веток и релизов:
- **закрытые цифры кабинетов:** YouTube Studio (досмотры, «просмотрено / пролистано», удержание на 0:10 / 0:30, CTR, показы, средний процент и время просмотра, доход, доли стран, устройств, пола и возраста); консоли Playgama, CrazyGames и других площадок (показы рекламы, доход, удержание, сессии, отказы); кабинет Авито (просмотры, контакты, расходы); Яндекс Вебмастер и Search Console (запросы, клики); счётчик сайта; CRM;
- продажи, заявки, клиентов, дизайнеров открытым текстом (только шифр или конверт), закупочные цены, поставщиков, проценты дизайнерам;
- ключи, токены, пароли, секреты, VPN-ключи, домашний адрес, личные телефоны и почты.

Можно: код; открытые цифры (просмотры с публичной страницы или RSS, подписчики, лайки, цены с сайта); выводы словами («досматривают хуже, чем коробку 1», «в основном Казахстан»).
Закрытое — только в документы проектов Claude (Projects) или в сообщение Михаилу.

## Каждый за собой
1. **Перед каждым `git commit`:** `python3 .claude/check_private.py --staged -m "<текст сообщения>"`.
   В клоне другой ветки скрипта нет — взять так:
   `git fetch --depth=1 origin main && git show origin/main:.claude/check_private.py > /tmp/check_private.py`.
   Нашлось — переписать словами или открытыми цифрами, проверить снова, потом коммитить.
2. **Когда начинаешь работу с веткой:** `python3 /tmp/check_private.py --history 50` в её клоне. Нашлось своё — убрать в тот же день.
3. **Если закрытое уже ушло в GitHub — убрать самому, не оставлять другим:**
   - из текущих файлов — новым коммитом;
   - из истории — `bash .claude/scrub_history.sh <ветка> "старый текст" "новый текст" [ещё пары…]` (сначала с `--dry`). Скрипт переписывает историю только этой ветки, проверяет, что старого текста не осталось, и пушит с `--force-with-lease`. Файлы на верхушке ветки меняются только там, где был старый текст;
   - ветку, куда параллельно пишут боты или другие чаты, переписывать в тихий момент; после этого старые клоны этой ветки не использовать — клонировать заново;
   - чужую ветку не переписывать: сказать Михаилу, в какой ветке и что нашлось;
   - Михаилу — одной строкой: что попало и что убрано. Старые версии ещё какое-то время могут открываться по прямой ссылке, пока GitHub их не удалит; совсем — только через поддержку GitHub с его аккаунта.
4. Проверка ловит не всё (проценты рядом с метриками, «показы N», «0:30 — N%», ключи). Думать самому: если цифру не видно на публичной странице — это закрытое.
