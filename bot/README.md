# Telegram-бот магазина «Пространство»

Бот магазина декора ARTDEC в Санкт-Петербурге: реечные панели, панели под дерево и бетон,
молдинги, плинтусы, карнизы, уголки. Работает на сервере Selectel (Ubuntu 24.04), который
настроен скриптом `setup-prostranstvo.sh` из этой же ветки.

## Установка — одна команда (от root)

Токен бота выдаёт @BotFather (`/newbot`).

```
curl -fsSL https://raw.githubusercontent.com/mikhailusenko88-hub/Mikhail/server/bot/install-bot.sh | bash -s -- 'ТОКЕН_ОТ_BOTFATHER'
```

С iPhone: в «Командах» — действие «Выполнить скрипт по SSH» для сервера Selectel, вставить
команду выше. Установщик в конце показывает имя бота и одноразовый код `/owner`.

Обновить бота (токен, настройки и база заявок не трогаются):

```
curl -fsSL https://raw.githubusercontent.com/mikhailusenko88-hub/Mikhail/server/bot/install-bot.sh | bash
```

Параметры: `--new-code` — новый код для `/owner`; `--site-url https://ДОМЕН` — адрес сайта
для ссылок (`--site-url -` — без ссылок); `--force` — ставить не на сервер сайта (не нужно).
Без `--site-url` адрес берётся из `/etc/prostranstvo/prostranstvo.conf` (домен сайта).

## Команда магазина: роли

| Роль | Что получает | Что может |
|---|---|---|
| **менеджер** | все сообщения клиентов, заявки, статусы отгрузок | отвечать клиентам, «Передать на отгрузку», приглашать и убирать людей, статистика |
| **отгрузка** | заявки и карточки «На отгрузку» (все сообщения — по желанию) | «Принял», «Отгружено», читать переписку, отвечать клиенту |

1. **Менеджер**: открыть бота, «Старт», отправить `/owner КОД` (код показал установщик;
   одноразовый — кто первым отправит, тот и станет менеджером).
2. **Второй человек**: менеджер нажимает «Команда» → «Пригласить на отгрузку» (или
   «Пригласить менеджера»), бот даёт код на 24 часа. Человек открывает бота и отправляет
   `/join КОД`.
3. «Команда» — список и кнопки «Убрать»; «Уведомления» — получать все сообщения клиентов
   или только заявки и отгрузки (`/notify all` / `/notify orders`).

Ответить клиенту: смахнуть влево его сообщение, заявку или «Переписку» и написать ответ —
бот отправит его от имени магазина (можно фото и файлы). Или `/reply 12 текст`
(12 — номер заявки).

### Отгрузка

Статусы заявки: **новая → подтверждена → на отгрузке → отгружено**.

1. Под заявкой у менеджера кнопка «Передать на отгрузку». Бот спрашивает: что отгрузить
   (по умолчанию — расчёт из заявки, можно написать своё), адрес или «Самовывоз»,
   когда, телефон получателя (по умолчанию — из заявки). Менеджер проверяет и подтверждает —
   статус «подтверждена».
2. Карточка «На отгрузку №…» приходит всем с ролью «отгрузка» с кнопками «Принял»
   (статус «на отгрузке») и «Отгружено» (статус «отгружено»).
3. Менеджеру приходит сообщение о каждом статусе. «Отменить отгрузку» — у менеджера.
4. «Отгрузки» (`/orders`) — что сейчас не отгружено.

Кнопки меню сотрудников: «Заявки», «Отгрузки», «Рассчитать стену», «Каталог и цены»,
«Команда» и «Статистика» (у менеджера), «Уведомления», «Помощь». Те же действия командами:
`/leads`, `/lead N`, `/orders`, `/history N`, `/reply N текст`, `/team`, `/invite manager|shipping`,
`/remove ID`, `/notify all|orders`, `/stats`, `/reload` (перечитать цены с сайта).

## Для клиентов

- **Рассчитать стену**: группа → артикул (кнопки или текстом, например `A907`) → размеры.
  Панели: `штук = ceil(ширина / ширина_панели) × ceil(высота / длина_панели)` + 7 % запаса
  (вверх). Погонаж: `штук = ceil(метры × 1,07 / длина_планки)`. Ввод: «3,2», «3.2», «320 см»,
  «3200 мм», сразу «3,2 x 2,7». Ответ: штуки, полные коробки + остаток поштучно, ориентировочная
  сумма (цены предварительные), кнопки «Отправить расчёт менеджеру» и «Посчитать другой».
- **Каталог и цены**: цена за штуку и за коробку; ссылка на сайт, если задан `SITE_URL`.
- **Оставить заявку**: имя → контакт (кнопка «Отправить номер», телефон текстом или «Напишите
  мне в Telegram») → комментарий (можно пропустить) → согласие на обработку персональных данных
  (ссылки на `consent.html` и `privacy.html` сайта или короткий текст, если сайта нет).
  Без «Согласен» ничего не сохраняется.
- **Связаться с менеджером** или просто сообщение в чат — уходит команде магазина.
- `/delete_me` — клиент сам удаляет свои заявки и переписку (отзыв согласия). Заказы, уже
  переданные на отгрузку, остаются — их хранят по договору и закону.
- Ссылки с сайта: `https://t.me/ИМЯ_БОТА?start=calc` (расчёт), `?start=catalog`, `?start=lead`,
  `?start=A907` (сразу расчёт артикула).

## Где что лежит

| Что | Где |
|---|---|
| код бота | `/opt/prostranstvo-bot/app` (копия папки `bot/` ветки `server`) |
| Python и библиотеки | `/opt/prostranstvo-bot/venv` |
| настройки и токен (секретно, chmod 600) | `/etc/prostranstvo/bot.env` |
| база: заявки, отгрузки, переписка, команда | `/var/lib/prostranstvo/bot.db` (только на сервере) |
| кеш каталога | `/var/lib/prostranstvo/bot-catalog.json` |
| служба | `systemctl status prostranstvo-bot`, журнал `journalctl -u prostranstvo-bot -n 50` |
| журнал установки | `/var/log/prostranstvo-bot-install.log` |

Каталог и цены — из массива `const CAT=[...]` в `index.html` сайта: сначала
`/var/www/prostranstvo/index.html`, если не вышло — GitHub (ветка `mebel`), потом последняя
удачная копия. Перечитывается раз в час (сразу — `/reload`).

## Данные и безопасность

- Репозиторий открытый: в коде нет токенов, телефонов, адресов. Токен — только в `bot.env`.
- Данные клиентов — только в базе на сервере в России и в чатах сотрудников; в журнал
  телефоны, имена и тексты сообщений не пишутся.
- Коды `/owner` и `/join` одноразовые, защищены от подбора (5 попыток в час на человека).
- Служба работает от пользователя `prostranstvo` и может писать только в `/var/lib/prostranstvo`.

## Настройки `bot.env`

`BOT_TOKEN`, `SITE_URL`, `OWNER_CODE`, `CONSENT_VERSION`, `ADMIN_IDS` (постоянные менеджеры по
Telegram id — обычно не нужно), `OPERATOR_NAME` (для текста согласия без сайта),
`YANDEXGPT_ENABLED=0` + ключи — заготовка (выключена) для черновиков ответов: черновик видит
только сотрудник, клиенту автоматически ничего не уходит (см. `yagpt.py`).
После правки: `systemctl restart prostranstvo-bot`.
