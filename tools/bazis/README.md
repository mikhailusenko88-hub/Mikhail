# Базис-Мебельщик → 3D-проверка (кромка, крепёж, присадка, ящики)

Запуск: `tools/bazis/run.sh файл.b3d папка_вывода "Заголовок"` (WALLS=1 — добавить стены гардеробной 2370×1970 из шаблона).
Результат: `view.html` (публиковать как артефакт), `hardware.txt` (вся фурнитура и отверстия), `drawers.txt` (фасады/короба ящиков).

- bz.py — контейнер BZ85 (типы записей 0–9, 8 = пустое значение).
- extract.py — панели (контур, материал, кромка по элементам контура: поля ed/ne), профили, ящики/корзины/брючница (movers), сетки фурнитуры.
- post.py — габариты деталей, коды модулей (Л1, П2, ПР1…).
- fastjson.py — крепёж и присадка по Holes фурнитуры: шканты, конфирматы, эксцентрики, саморезы, ножки, наколки, направляющие (вкл. Unihopper 3x3/6x10), полкодержатели, стяжки; f[9] = название из Базиса.
- list_hw.py — сводка фурнитуры: шт., отверстий, Ø×глубина. furninfo.py — полная запись фурнитуры по шаблону имени.
- drw.py — размеры фасадов и коробов ящиков. build.py + template.html + edge.js — страница (Кромка / Прозрачно / Крепёж, нажатие на деталь или отверстие → карточка).
