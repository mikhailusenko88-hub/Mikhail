# Сравнение героя с образцом (обложкой) — цифрами, а не на глаз

1. `obl.json` — ручная разметка героя на обложке: эллипсы глаз (центр, ширина, высота) с радужкой, нос, верх губы,
   контур головы (левый и правый край на уровне глаз, макушка), уши. Проверка разметки: `show.py` рисует её поверх обложки.
2. `poza.py <hero> <ключ>` — сам подбирает ракурс моего героя под обложку (поворот — по смещению носа от середины головы,
   наклон — по высоте макушки) и печатает таблицу мерок в долях ширины головы: обложка / мой / разница.
3. `tri.sh <hero> <ключи…>` — то же сразу по нескольким обложкам.
4. `avtopodbor.py <hero> <ключи…>` — каждая мерка привязана к одному числу героя (глаза — EYE_XZ, RE, EYE_S, EYE_K, EYE_TILT;
   нос — NOSE_Z; рот — LIP_Zf); производные один раз, потом шаги Ньютона, пока среднее расхождение < 3%.
   Числа не пишутся в файл сами — итог в `/home/claude/out/geroi/avtopodbor_<hero>.json`.
5. `krug.sh` — голова с пяти сторон; `sravni34.py`, `ryadom.py` — рядом с обложками в одном масштабе и наклоне; `setka.py` — «тюль».
Мерки моего героя снимаются с карты меток `prev_cvet.py` (`LBL=1`): центр глаза — середина видимого глаза, как на обложке;
к ширине головы прибавляется мех (по умолчанию 12 мм с каждой стороны).
Ловушка: цифры совпали — ещё не значит «похож». Каждый шаг смотреть глазами рядом с обложкой: выражение (брови, рот),
мех, свет, цвет цифрами пока не меряются.
