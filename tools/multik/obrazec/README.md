# Образец движка «Мультиков» — Барсик, Пик и Рон (версия 6.2, 3 ноября 2026)

Проверочная страница, на которой телефон сам собирает сцену: качает героев (12 МБ), выращивает шерсть и траву, один раз запекает свет и рисует ролик с замером.
Это **образец** — в приложение «Замер 3D» пока ничего не перенесено. Берётся за основу для глобального обновления раздела «Мультики» (звук, улучшения, модули).

Страница: `page/` (открыть `page/index.html` с любого https-хостинга; three.js r169 берётся с cdn.jsdelivr.net).

## Что утверждено Михаилом

- **Пик** — серый мышонок с красным бантиком у правого уха. Голова круглая и большая, уши крупные, носик — розовая бусинка, улыбка и два зубика, румянец на щёчках, хвостик гладкий.
- **Глаза Пика** (основа): овальные (`EYE_S = 0.88 × 1.12`), радужка маленькая, белка много (`EYE_K = (0.76, 0.935)`), тёмно-карие, книзу светлее (`IRIS_STYLE = 1`).
  Глаза сдвинуты ближе к носу (`EYES = ±0.045, -0.08, 0.425`). Зрачок почти прямо вперёд (`EYE_CENTER = (0.1, 0.45)`) — без косоглазия.
  Образцы: `show/pik_zrachok.jpg`, вариант 3.
- **Глаза Рона** — так же: ближе к носу, зрачок прямо, слегка овальные (`show/ron_glaza.jpg`).
- **Лапки с пальцами у всех троих**:
  - у Пика — розовые ручки с 4 пальчиками и большим пальцем, длинные ступни с пальцами;
  - у Барсика и Рона — круглые пальцы с бороздками и короткой шерстью;
  - подушечки: у Барсика розовые, у Рона тёмные.
- **Жесты**: Барсик машет лапой подушечками вперёд, у мордочки (`show/barsik_privet.png`). Рон «даёт лапу» (`show/ron_daet_lapu.png`).
- **Рон**: белая кепка козырьком назад, красный ошейник с золотым жетоном.

## Как устроено (модули, которые можно переносить)

- `page/engine6.js` — весь движок (WebGL2, three.js r169):
  - **Данные героя v6.1**: координаты — разности соседних точек (байты отдельно), номера треугольников — «шаг назад» переменной длины. Нормали считает телефон, пропуская крышки срезов (`cut`). Файлы — gzip с расширением `.wasm`.
  - **Шерсть растит телефон** (`growFur`) по правилам из `info.fur`: регионы 0–8, 9 — пальцы (короткая шерсть), 12 — подушечки (голые).
  - **Траву растит телефон** (`growGrass`, `env.json → grass_gen`).
  - **Запекание света** (`OB.bake`, async): идёт порциями, экран не замирает, показывает ход.
  - **Память телефона**: Cache Storage, ключ `ob-<OB.ver>`. При каждой новой выкладке менять `OB.ver` в `page_template.html`.
  - **Глаза**: глаз и овал стоят по осям головы, радужка повёрнута отдельно (`eyeDirs`, `eyeS`, `eyeK`, `irisS`, `uEyeM` с `irisInv`).
  - **Ступни** — отдельная кожа `feet` (мелкая сетка для пальцев), шов с телом по плоскости `ANKLE`.
- `page_template.html` — страница: экран загрузки (шаг, %, МБ, МБ/с, прошло/осталось), герои, планы (общий/средний/крупный/мордочка/лапки), стадии «глина → шерсть → свет», ролик 5 с с замером.

## Как пересобрать

1. Герои (Python 3 + numpy + scikit-image):
   ```
   cd heroes
   python3 hero_export.py pik
   python3 hero_export.py ron
   python3 hero_export.py barsik
   ```
   Пишет в `/home/claude/obrazec/data4` (или в папку из `OUT=`).
   Барсику нужна ветка `blender-test`, развёрнутая в `/home/claude/bt` (`build_geo.py`), и `out/anim.npz` — его делает `python3 anim_geo.py`. Лапы Барсика с пальцами задаются в `hero_export.py`, а не в `build_geo.py`.
2. Предпросмотр формы: `python3 prev2.py hero_pik pikA face 34 hand foot`. Центр видимой части глаза: `python3 eye_open.py hero_pik`.
3. Страница: `build_pub6.sh` (пути внутри абсолютные — `/home/claude/obrazec`) собирает `pub6/` из `page_template.html`, `engine6.js` и данных.
4. Проверка без телефона: `tests/cal6.js` (кадры через Playwright + swiftshader), `tests/quick.js` (два открытия подряд — второе из памяти).
