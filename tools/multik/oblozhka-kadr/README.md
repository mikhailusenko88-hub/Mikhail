# Обложка серии

## Главный способ (с 15.11.2026) — постер, как делает приложение

Кнопка «🖼 Обложка» в приложении теперь собирает **постер** (`Resources/Mebel/multik-poster.js`):
все герои серии (до 5) крупно — основа картинки, главный предмет по своему правилу, фон — место первой сцены, надпись маленькая.
Каждого героя и предмет движок снимает отдельно на ровном фоне — чёрном и сером (`MK3D._studio`), по разнице двух кадров получается
прозрачность вместе с шерстью. Старая обложка «одним кадром» — настройка `cover: 'scene'`.

Правила (меняются в `multik-poster.js`):
- **Герои** — все, у кого есть реплики, по числу реплик; герой сериала («Кот Барсик» → Барсик) всегда первый и самый крупный.
- **Мордочки** — эмоция героя в первой сцене (смех, грусть, страх → «радостно» или «удивлённо»: глаза открыты, лицо светлое);
  каждый говорит «Ура-а-а!» или «Ого-о-о!», кадр — когда рот открыт. Над головой ничего («!», сердечки) — в студии выключено.
- **Главный предмет** (строка `ГЛАВНОЕ:` или по названию):
  луна, радуга, солнце, змей, шарик, самолёт, ракета — в небе за героями;
  лодка — на воде с кругами (если место у воды, иначе как маленькая вещь);
  дерево, замок, дверь, палатка, снеговик — большим за героями;
  лужа — рисуется сама (синее пятно с бликами и кругами);
  остальное (жёлудь, компас, зеркальце, шишка…) — крупно в центре с сиянием.
- **Схемы** по номеру серии: N%3=0 — «по бокам» (главный слева), 1 — то же зеркально, 2 — «по центру» (главный в центре, вещь впереди).
  Соседние серии всегда выглядят по-разному.
- **Надписи**: логотип сериала слева сверху, «СЕРИЯ N» справа сверху, вопрос из названия — маленький свиток в нижнем углу
  напротив главного героя, две строки поровну, большими буквами.
- Два файла: с надписями и «(без надписей)».

В облаке то же самое: `node ../test/poster.js сценарий.txt [--hq] [--out=папка]` (строки ПЕРСОНАЖ для Барсика, Пика и Рона добавить,
three.js r169 и данные героев из `bars-install` — см. ../test/README.md). Без `--hq` — черновик за 15 секунд (проверить расстановку),
с `--hq` — как в серии, около 20–40 минут.

## Ручная сборка (если нужно что-то особенное)

- `../test/studio.js сцена.txt t…` — кадры героев на чёрном и сером фоне; `../test/propstudio.js тип папка` — предмет так же.
- `python3 cutout.py` — вырезка по двум кадрам; `python3 sostav.py план.json Обложка.jpg` — сборка по плану
  (`{bg, crop?, blur, series, text "A|B", text_at, items:[{img,x,y,h,flip?,glow?} | {splash:true,cx,cy,w}]}`).
- Старый способ «один кадр + плашки»: `tl.js`, `render.js --hq`, `extras.py`, `compose.py кадр.png Обложка.jpg "СЕРИЯ N" "ВОПРОС|СТРОКА?!"`
  (не брать кадры 2–6,2 с — там заставка сборки 59).
