# БАРС-озвучка

Произношение и голоса «Мультиков». Ветка `bars-ozvuchka` (на утверждении у Михаила — в `mebel-3d` не вливать и на телефон не ставить, пока он не скажет).

## Что это
1. **Произношение — один «мозг» для всех голосов** (`Resources/Mebel/multik-bars-rech.js`, `BARSRech`).
   Путь текста: словарь пользователя → числа словами → словарь исправлений → **грамматика** → омографы по смыслу (нейросеть) → модель ударений.
   - Грамматика (`BARSRech.rule`) решает раньше нейросети: «у две́ри / на двери́», «из до́ма / высокие дома́ / сидели до́ма», «в лесу́ / к ле́су»,
     «две руки́ / мои ру́ки», «выпил воды́», «уже́ темнее / стала у́же», «она начала́ петь / с самого нача́ла».
   - Нейросети омографов даётся только своё предложение (соседнее её сбивало).
   - Голоса iPhone: `MKVoice.homoMarks` считается в процессе голоса (страница voice.html). С 3 ноября 2026 этой функции в странице не было
     (прокси `window.MKVoice` её не отдавал) — у Пика, Рона и остальных героев с голосом iPhone омографы не разбирались вообще.
2. **Управляемый нейроголос** (`Resources/Mebel/multik-bars-golos.js`, `BARSGolos`). В `MKVoice.chunk` есть «режиссёр» (`o.shape`): можно задать
   длительность и высоту каждого звука модели. На этом построены:
   - смех голосом героя в ритме, мелодии и громкости настоящего смеха (шаблоны сняты с банка смехов, `G.LAUGHS`);
   - протяжные слова: «Ура-а-а!» (раньше читалось «ура, а, а», «Не-е-ет» — «не, е, ёт»);
   - звуки голосом героя: «Мяу!», «Мур-р-р», «Гав-гав», «Пи-пи-пи», «Ку-ку», «Му-у-у», «Бе-е-е», «Ква-ква», «Кря-кря», «Кар», «Ку-ка-ре-ку», «И-го-го»,
     «Ж-ж-ж», «Ш-ш-ш», «Тс-с», «М-м-м», «А-а-а», «Апчхи», зевок, плач, «Ля-ля-ля» по нотам (`G.SOUNDS`, `G.SOUND_WORDS`);
   - паспорт голоса: тон (P) и тембр (F) раздельно — модель говорит ниже и медленнее в F раз, запись ускоряется в F раз (без растяжки звука);
     живость интонации (R), эмоции (`G.EMO`).
   Вызов: `MKVoice.speak(text, { model, speaker, lex, bars: {…} })` — обычный JSON, проходит через мост iPhone (MultikVoiceHost), Swift менять не надо.

## Что не меняется
Обычные реплики Барсика (xenia, тон ×1,12, темп ×0,9286), Пика и остальных героев с голосом iPhone, рассказчика — звук тот же до отсчёта.
Через БАРС идут только: смех героя с нейроголосом (`MK.barsLaugh`), реплики с протяжными словами и звуками (`BARSGolos.needs`), герои с паспортом `c.golos`.
Смех по-старому: `lib.settings.bars = { oldLaugh: true }`.

## Проверка без телефона (обязательно перед установкой)
- `node tools/multik/test/rech.js` — 322 проверочные фразы с известным ударением (из них часть — настоящие реплики серий 9, 10, 21). Должно быть 322 из 322.
  `--old` — как было до БАРС-озвучки (288 из 322).
- `node tools/multik/test/golos.js same <папка Resources/Mebel прежней версии>` — серия `golos.txt`: обычные реплики обязаны совпасть один в один
  (ключ, голос, параметры); по-новому идут только смех Барсика и реплики с «Ура-а-а» / «Мяу».
- Звук: ветка `golos` (без кода приложения), workflow `golos-check`: речь из `in/*.flac + .txt` — анализатор (слова, ударения, UTMOS),
  звуки из `snd/` — распознаватель AudioSet (смех это или речь). Workflow `golos-ep` — «послушать» готовую серию (`ep_request.txt`).
  С музыкой под голосом ударения в готовых сериях анализатор определяет ненадёжно (много ложных тревог) — верить только тексту расшифровки.
- YouTube с серверов GitHub не скачивается («подтвердите, что вы не робот»). Звук серии берётся в браузере Мака: `video.captureStream()` + MediaRecorder
  на скорости ×2 (`preservesPitch = false`), сохранение через ссылку `download` — файл появляется в «Загрузках» как скрытый
  `.Q6L2SF6YDW.com.anthropic.claudefordesktop.*`; потом `asetrate=24000` возвращает скорость.
