# Новый мужской голос «ничей» (12.11.2026)
Модель — Silero v5 CIS (та же, что Альбина; в телефоне voice/front.onnx, enc.onnx). Диктор в ней — строка в трёх таблицах отпечатков
(front: dp.spe.weight, pp.spe.weight [60×64]; enc: spe.weight [60×128]). Новый голос = смесь строк мужских дикторов, подогнанная по длине
к обычной строке (без подгонки голос «плывёт»: UTMOS 1,3), вписанная на место неиспользуемого диктора-двойника (bak_/tat_/erz_…).
`python3 make.py <папка voice> recipes2.json` — пишет front.onnx, enc.onnx, tts.json (имена nw1…nx6).
Пробы для Михаила: 1 — nw1 (доли: Александр .8, Богдан .6, Дмитрий 1.3, Эдуард 1.2, Игорь 1.2, Роман .6),
2 — nx6 (шесть дикторов поровну + направление в сторону от всех, сид 6, β 1.0), 3 — nv4 (Богдан + Эдуард + Игорь).
Проверка (workflow golos-nv): UTMOS 3,62 / 3,75 / 3,26; ошибок распознавания 0; сходство с ближайшим реальным диктором (ECAPA) 0,63 / 0,65 / 0,62,
у того же диктора в разных фразах 0,84–0,97.
