# Каталог для Авито картинками

В чат Авито нельзя вставить ссылку или файл — уходят только картинки. Поэтому каталог нарезан на вертикальные листы
под экран телефона: фото, артикул, размер, цена за штуку. Без марки поставщика, названия магазина, контактов и ссылок.

Листы лежат в CRM: «Ещё → Каталог для Авито» (страница с поиском по артикулу и кнопкой «Поделиться»), сами файлы —
в «Документах», раздел «Каталог для Авито». Страница сверяет цены на листе с ценами CRM и помечает устаревшие листы.

## Как пересобрать (после смены цен, фото или состава каталога)
1. Каталог и фото сайта — ветка `mebel`, папка `0f7s1eez`: `index.html` (CAT, PHOTO) и `img/2x/*.jpg` (только главные фото, без `_2`, `_3`).
2. Живые цены CRM: `https://crm.nashdekor.ru/api/catalog` снять через page-fetch (ветка `domain-check`, `pages/urls.txt`),
   сохранить как `{"артикул": цена}`.
3. `python3 make_sheets.py <index.html> <папка img/2x> <куда> [цены.json]` → `avito-NN.jpg` и `manifest.json`
   (состав листов и цены на момент сборки). Нужны PIL и шрифт Inter (`/usr/share/fonts/opentype/inter/`).
4. Посмотреть листы глазами. Положить в CRM через ветку `outbox`, по одному конверту на лист:
   `python3 tools/doc.py --folder "Каталог для Авито" --title "<title из manifest>" --note "Цены на ДД.ММ.ГГГГ: A703 — 475, …" --replace avito-NN.jpg`
   Имена файлов `avito-NN.jpg` не менять — по ним новая версия заменяет прежнюю. Заметка «Цены на …» обязательна: по ней CRM сверяет цены.
   Пушить партиями по 7 с паузой в минуту (сервер качает с GitHub медленно); после статуса `saved` убрать конверты из ветки.
   Если лист с таким номером больше не нужен (листов стало меньше) — удалить его в CRM: «Документы → Изменить → Удалить».

Первая сборка — 23.11.2026: 21 лист, 107 позиций, цены совпали с CRM.
