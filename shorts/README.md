# Shorts с арены Flagball Arena

Камера-зритель (`index.html?spec`) заходит на арену без своего шарика, сама выбирает самый интересный
шарик (крупный, рядом добыча или угроза, недавно кого-то съел), а когда его съедают — переключается на съевшего.

- `record.js` — ждёт, пока до конца раунда стран останется CLIP секунд, снимает 1080×1920 до итога раунда
  и ещё 6,5 с после него, кладёт звук и пишет `meta.json` (название, описание, победитель).
- `mix.py` + `audio.py` — своя музыка (тот же синтезатор, что у роликов канала), «чпок» на поедания,
  отсчёт последних 5 секунд, фанфары победы.
- Запуск в GitHub: изменить `request.txt` → workflow `arena-shorts` → ветка `arena-shorts`.
- Локально: сервер `TEST=1 ROUND_LEN=40 node online/server.js`, страница на :8770, `CLIP=25 node shorts/record.js out`.
