# Скрипты для формы «Разместить объявление» на Авито

Нужны, чтобы выкладывать объявления «Наш декор» через встроенный браузер приложения Claude
за минимум подтверждений. Порядок работы и все ловушки — в навыке `avito-vykladka`
и в заметке проекта `claude/artdec-avito.md`.

Каждый файл вставляется целиком в один вызов `javascript_tool` на вкладке Авито.

| Файл | Что делает | Где запускать |
|---|---|---|
| `s1-zapolnit.js` | Название → категория → вид → переключатели → размеры, цена → фото → страна → описание; ставит поле адреса по центру экрана. Менять только блок `AD` в начале. Журнал — `sessionStorage.nd_log`. | чистая страница `/additem` |
| `s2-adres-final.js` | Выбирает первую подсказку «Санкт-Петербург», ждёт, пока Авито пересчитает блок доставки, выключает «Самовывоз с онлайн-оплатой», проверяет все поля, нажимает «Продолжить». Возвращает журнал. | та же форма, после настоящего клика в поле адреса и настоящего ввода «Санкт-Петербур» |
| `s3-proverka.js` | Читает номер объявления из адреса страницы оплаты и сверяет название, цену, параметры, описание. | страница оплаты `/account/fee?item_id=…` |

Состояние на 10.11.2026: части скриптов проверены на объявлениях A910, 3-7, 3-15, 3-9, A703.
Целиком в этом виде `s1` и `s2` ещё не запускались — после первого запуска сверить журнал
и поправить здесь.

Оплату скрипты не трогают: её делает Михаил сам.
