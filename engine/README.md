# Honeycomb Engine — свой фотореалистичный рендер (C++ path tracer)

Мир собран из невидимых ячеек-«молекул» (гексагональная сетка 1,6 м): ~10 образцов травы повторяются ~1900 раз,
свет в ячейках запечён заранее (видимость солнца и неба на каждой травинке), в кадре считается только то, что меняется.

## Сборка и запуск (ничего ставить не нужно: g++ + ffmpeg)
    g++ -O3 -march=native -ffast-math -fopenmp -DLEAFN=6 -o pt pt.cpp
    ./pt 0 240 1280 720 4 out          # кадры f_0000.ppm… (24 к/с, 10 с = 240 кадров)
    ffmpeg -framerate 24 -i out/f_%04d.ppm -i audio.wav -vf scale=1920:1080:flags=lanczos \
      -c:v libx264 -b:v 10000k -pix_fmt yuv420p -c:a aac -shortest -movflags +faststart video.mp4
Аргументы: кадр_от кадр_до ширина высота spp папка. Звук: `python3 audio.py` (нужен landings.json — времена приземлений).

## Скорость (2 ядра облака, 1280×720)
полная трассировка 20 с/кадр → запечённый свет 8,4 → грубая трава вдали 4,0 → адаптивные лучи + подвыборка расфокуса 3,1 с/кадр.
Следующий шаг ×100 — GPU телефона (Metal, аппаратная трассировка A17 Pro) с той же запечённой структурой.

Файлы: pt.cpp — движок; webgl_scene.html + webgl_render.js — первая (стилизованная) версия на WebGL; audio.py — синтез звука.
