# Neon — «неоновая основа»: мир из диодов с прошитым светом

Идея Михаила: поверхность не освещается в кадре, а сама знает, каким цветом ей гореть.
Трассировщик `pt.cpp` (не изменён) становится «заводом»: один раз считает отклик каждой точки
на солнце и небо и выгружает диоды. «Проектор» (`index.html`, WebGL2) рисует кадр без единого луча.

- `../neon_bake.cpp` — завод. Подключает `pt.cpp` как есть (`#define main pt_main`), прошивает
  10 образцов травы, землю, 3 дерева, выгружает `scene.bin` (диоды, ячейки, деревья, пыльца, кольца)
  и `frames.bin` (камера и герой на 240 кадров — те же `cameraFor`/`buildHero`).
  Сборка: `g++ -O3 -march=native -ffast-math -fopenmp -DLEAFN=6 -o neon_bake neon_bake.cpp`, запуск `./neon_bake web`.
- `index.html` — проектор: инстансы ячеек, ярусы по расстоянию, тень героя как диммер солнца,
  ветер, кольца примятой травы (dispAt из pt.cpp), туман, глубина резкости, блум, ACES, зерно;
  режим «Сравнить» со шторкой против кадра трассировки; ручка времени суток (диммеры).
- `shot.js` — проверка в headless Chromium: `node shot.js 120` → `shot_120.png` (нужен `python3 -m http.server 8765` в папке web).

Диод (16 байт): pos int16×3 · normal oct8×2 · albedo u8×3 · |n·sun|·vis u8 · sky vis u8 · доля высоты u8 · флаги
(сторона, солнце со стороны +n, фаза ветра). Земля — то же с float-позицией (24 байта).

Страница для телефона: http://89.126.192.214:8080/mebel/neonlug1/ (ветка `mebel`, папка `neonlug1`).
Замер совпадения с трассировкой (кадр 120, средний цвет по зонам, 0–255): небо 175/171, дальний луг 182/179,
средний луг 140/139, ближний луг 94/92, деревья 159/166 — трассировка/диоды.

## Барсик в лесу (`cat/`)
- `cat/cat_build.py` — кот из формул Blender-версии (`build_geo.py` из ветки `blender-test`): кожа (marching cubes), шерсть
  (117 тыс. волосков по 4 точки), нос, шарф, глаза, усы, рот + веса двух костей на точку (10 костей: тело, голова, 2 руки,
  2×2 ноги с коленом, 2 хвоста). Выход `cat.bin`. Перевод координат Blender (z вверх) → движок (y вверх, морда к −z).
- Сцена: `./neon_bake cat cat` — тропа с короткой травой x=6, z −29…−45, деревья с тропы убраны.
- `cat/index.html` — проектор: скиннинг в шейдере, шерсть лентами к камере (корни темнее, блеск по касательной,
  просвет на контровом), походка (бёдра, колени, руки, покачивание, хвост, голова), свободная камера (палец/щипок),
  кино-камера, дымка, лучи сквозь деревья, время суток.
- Страница: http://89.126.192.214:8080/mebel/barsik1/
