Приём заявок из других мест

Квиз, Яндекс Формы, Тильда, другой сайт — отправляют заявку по секретной ссылке, в CRM появляется новая заявка (источник «Другое», в тексте — название). Поля: name, phone, email, messenger, text (или по-русски: имя, телефон, почта, комментарий); остальные поля попадут в текст заявки. Не больше 60 заявок в час с одной ссылки.

Как подключить

Уведомления в Telegram — 3 минуты
  1. В Telegram откройте @BotFather → /newbot → придумайте имя → он пришлёт токен вида 123456789:AAE….
  2. Напишите своему новому боту любое сообщение (иначе он не сможет писать вам).
  3. Узнайте номер чата: напишите боту @userinfobot — он ответит вашим Id (цифры). Для группы: добавьте бота в группу, номер группы начинается с «-100».
  4. Здесь: «Куда» — Telegram, вставьте токен и номер чата, отметьте события → «Сохранить» → «Проверить».
Заявки в Google Таблицу — 5 минут
  1. Создайте Google Таблицу → меню «Расширения» → «Apps Script».
  2. Удалите всё в окне и вставьте код ниже → «Сохранить».
  3. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение» → «У кого есть доступ»: «Все» → «Начать развёртывание» → разрешить доступ → скопируйте ссылку «URL веб-приложения».
  4. Здесь: «Куда» — по ссылке, вставьте ссылку, отметьте события (и «Передавать контакты», если нужны телефоны в таблице) → «Сохранить» → «Проверить» — в таблице появится строка.

Make, Zapier, n8n, Albato и другие

Создайте в сервисе сценарий с приёмом вебхука (Webhook / Custom webhook), скопируйте его адрес https://… и добавьте здесь как «по ссылке». CRM шлёт JSON: event, event_name, deal (id, stage_name, total_rub, want, url, custom), client (name, company, custom; с галочкой — phone, email), payment, chat. Дальше в сервисе — куда угодно: таблица, почта, amoCRM, 1С.

Обратно — из сервиса в CRM: шаг «HTTP-запрос», метод POST, адрес из блока «Приём заявок», тело JSON: {"name": "…", "phone": "…", "text": "…"}.
